▶ YT Share Studio
브라우저 전용 · GitHub 자동 업로드

원하는 모습으로 영상 공유

유튜브 영상 주소와 커스텀 제목·썸네일을 입력하면 카카오톡 공유 페이지를 만들고 GitHub Pages에 자동으로 업로드할 수 있습니다.
별도 설치는 필요 없으며, 최초 1회 GitHub에서 제한된 권한의 토큰을 발급해야 합니다.

① 영상 링크 두 개 입력

공개 영상의 제목과 썸네일을 자동 조회합니다. 원본 설명 전문은 별도 API 키가 필요해요.

원본 영상 설명 전문도 가져오기 (선택 사항)

YouTube Data API v3 키를 이미 보유한 경우에만 입력하세요. 이 키는 코드에 저장되지 않습니다. 키가 없다면 위의 자동 안내문을 사용할 수 있습니다.

참고 영상 링크에서 자동으로 가져오거나 직접 이미지를 선택하세요.

이 주소를 기준으로 공유 URL과 이미지의 절대 주소를 생성합니다. 실제 공개된 사이트 주소를 입력하세요.

② GitHub 자동 업로드

현재 저장소: youdobe / yt-share-studio · 브랜치: main

⚠ 토큰은 서버나 브라우저 저장소에 저장하지 않습니다. 자동 업로드를 할 때마다 다시 입력해야 합니다. 공유하지 마세요.

GitHub 토큰 생성 페이지 열기 · 저장소는 Only select repositories → yt-share-studio, 권한은 Contents → Read and write로 설정하세요.

② 미리보기

썸네일 미리보기
참고 영상의 표시 정보 · 클릭 시 A 영상으로 이동
여기에 공유용 제목이 표시됩니다
설명을 입력해 보세요.
공유 사이트 주소
알아둘 점
이 편집기는 영상이나 유튜브의 정보를 변경하지 않습니다. 별도 공유 페이지를 만듭니다. 해당 페이지는 카카오톡이 OG 메타태그를 읽고, 방문자 브라우저에서는 JavaScript로 원본 유튜브에 이동하도록 시도합니다. 카카오톡 버전별로 동작이 달라질 수 있어 실제 테스트가 필요합니다.

③ 공유 방법

  1. 실제 재생 영상 A, 참고 영상 B 입력 → 자동 가져오기
  2. GitHub에서 발급한 Fine-grained 토큰 입력
  3. 「GitHub에 자동 업로드」 클릭
  4. 생성된 URL을 카카오톡으로 전송
  5. 배포 후 미리보기와 이동 동작 확인

참고 영상 썸네일은 원본 YouTube 이미지 주소를 사용합니다. 이미지를 직접 선택하면 GitHub에 업로드합니다. ZIP 수동 생성도 가능합니다.

설정은 브라우저에 자동 저장되지만 다른 PC와 자동 동기화되지는 않습니다. 설정 파일 저장/가져오기를 사용할 수 있습니다.
